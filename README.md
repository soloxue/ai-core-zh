## 这是什么,给谁看

这不是又一本"5 分钟讲清 AI"的速成手册。

市场上有两类 AI 内容:一类是工具书 / 教科书,公式和代码堆得满满当当,但只有同行能看懂价值;另一类是短视频"标题党",听完觉得懂了,事后一想啥实质收获都没有。

这里走第三条路:**用程序员能接受的方式,把 AI 核心技术的底层逻辑讲透。** 不回避硬核的东西(梯度下降、反向传播、Transformer),但也不陷进数学细节里出不来;每一个概念,都拆到"为什么会出现、解决了什么关键问题"这一层。

适合的读者:

- 程序员,想搞懂平时调用的那些模型到底在干什么
- 有一定技术基础、对 AI 底层逻辑好奇的人
- 愿意为有价值的知识花点心思、动点脑筋的人

这不是读无脑爽文的地方。

## 叙事主线

AI 的技术演进不是一堆冰冷算法的迭代,而是一群鲜活的、甚至偏执的天才,在一次次思想碰撞、路线之争、乃至人生沉浮中推动的。所以这个系列**故事与技术双线并重**:从 100 多年前讲起,认识那些把 AI 从朦胧设想一步步做成今天这个样子的人,同时把背后的核心技术一层层拆开。

整体路线:

```
第一幕:思想溯源
  亚里士多德 -> 布尔 -> 图灵 -> 香农/维纳/冯诺依曼 -> 达特茅斯会议
       │
       ▼
第二幕:路线之争与机器学习
  符号主义 vs 连接主义 -> 第一次AI寒冬 -> 机器学习三派
       │
       ▼
第三幕:神经网络的诞生与突破
  MCP -> 感知机 -> 梯度下降 -> 异或之殇 -> 信用分配 -> 反向传播
  -> 激活函数演进(阶跃->Sigmoid->ReLU)
       │
       ▼
第四幕:深度学习崛起
  CNN/LeNet -> ResNet -> RNN/LSTM/GRU -> 2014奇迹年(Seq2Seq)
       │
       ▼
第五幕:生成式 AI 时代
  注意力机制 -> Transformer -> Ilya的故事 -> Diffusion x Transformer
```

每一期都从上一期留下的问题出发,不堆砌,是一条因果链。
